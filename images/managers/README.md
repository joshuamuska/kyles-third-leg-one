# Manager photos

Drop one photo per manager in this folder, named after their ID in `managers.json`: `josh.jpg`, `brett.jpg`, `kyle.jpg` and so on. Anyone without a photo gets a placeholder with their initials.

- **Shape:** square. The site crops to a square, so anything else loses its edges.
- **Size:** 600 × 600 pixels. Bigger works but just makes the page slower.
- **Format:** JPG (or WebP), ideally under 150 KB.
- **Framing:** face roughly centered, with a little room above the head.

To use a different file name or format, change that manager's `photo` in `managers.json`.
